 # IOServe - A Native Golang based MCP Server for Native I/O operations across Windows and Linux Systems

 --- 

 This system is designed as an mcp server that provides tools to general LLMs to create, delete and modify files and related data. Additional functionality may include browser operations. This can be categorized as an MCP Server, as it provided guarded access to LLMs for accessing and controlling critical stuff within user space under strict supervision, with root assumption being that the AI will by all means go rogue. 

 `Side Note:` This is a smaller part of a bigger project, known as project `Raven`, which will be later discussed.
